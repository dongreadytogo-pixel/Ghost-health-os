# 04 — Final Cut Pro Keyboard Shortcuts

Source: Final Cut Pro User Guide → Keyboard shortcuts
(https://support.apple.com/guide/final-cut-pro/keyboard-shortcuts-ver90ba5929/mac).
Reference for the Workflow Extension and docs; customizable via
FCP → Commands → Customize (⌥⌘K).

## Editing
| Action | Shortcut |
|---|---|
| Append to storyline | E |
| Insert | W |
| Connect to primary storyline | Q |
| Overwrite | D |
| Blade at skimmer/playhead | ⌘B |
| Blade all lanes | ⇧⌘B |
| Delete (ripple) | ⌫ |
| Replace with gap (lift) | ⌦ |
| Enable/disable clip | V |
| Create audition | ⌘Y |
| New compound clip | ⌥G |

## Timeline & navigation
| Action | Shortcut |
|---|---|
| Zoom in / out | ⌘+ / ⌘− |
| Zoom to fit | ⇧Z |
| Snapping toggle | N |
| Skimming toggle | S |
| Go to start / end | Home / End |
| Previous / next edit | ↑ / ↓ |
| Nudge 1 frame left/right | , / . |
| Timeline index | ⇧⌘2 |

## Playback
| Action | Shortcut |

| Play/pause | Space |
| Play backward / stop / forward | J / K / L |
| Play around edit | ⇧/ |
| Loop playback | ⌘L |
| Play full screen | ⇧⌘F |
