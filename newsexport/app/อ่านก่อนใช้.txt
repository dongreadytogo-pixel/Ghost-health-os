แยกงานข่าว  รุ่น 6.2
=====================

แก้เรื่องตั้งค่า Roles ไม่สำเร็จ
----------------------------------

สาเหตุที่รอบก่อนทำไม่ได้
รุ่นก่อนสั่งให้ไล่ดูของทุกชิ้นในหน้าต่างเพื่อหาช่องเลือก
แต่หน้าต่าง MXF-50 มีของเยอะมาก
มันจึงใช้เวลาเกิน 12 วินาที แล้วถูกตัดทิ้งก่อนจะเจอช่องนั้น

รุ่นนี้เปลี่ยนเป็นชี้ตรงจุด ไม่ไล่ดูทั้งหน้าต่างอีก
เพราะภาพที่คุณส่งมาบอกโครงสร้างชัดเจนแล้ว

  หน้าต่างชื่อ MXF-50
  มีแถบแท็บ  Info  Settings  Roles
  ใต้แท็บมีช่อง Roles as เป็นช่องแรกของหน้าต่าง

ลำดับที่โปรแกรมทำ
  1. เปิดแท็บ Roles
  2. อ่านค่าปัจจุบัน ถ้าเป็น 3 Stereo อยู่แล้วก็ข้ามไปเลย
  3. ถ้าเป็น Multitrack MXF File ให้เปิดช่องเลือกแล้วเลือก 3 Stereo
  4. อ่านค่าซ้ำเพื่อพิสูจน์ว่าเปลี่ยนจริง

ข้อ 4 สำคัญมาก
เพราะบทเรียนที่ผ่านมาคือ ห้ามเชื่อว่าคลิกแล้วสำเร็จ
ต้องพิสูจน์ด้วยค่าที่อ่านได้จริงเท่านั้น


ถ้ายังตั้งไม่ได้
------------------
โปรแกรมจะหยุดแล้วบอกให้คุณตั้งเอง
โดยบอกด้วยว่าตอนนี้ค่าเป็นอะไร และต้องเปลี่ยนเป็นอะไร
ไม่ปล่อยให้ได้ไฟล์ที่ตั้งค่าผิดแบบเงียบ ๆ

และบันทึกจะจดไว้ครบ
  เปิดแท็บ Roles ได้หรือไม่
  หน้าต่างที่เปิดอยู่มีชื่ออะไรบ้าง
  ค่า Roles as ก่อนตั้ง และหลังตั้ง เป็นอะไร


ค่าที่ถูกต้องสำหรับไฟล์ mxf ตามที่คุณส่งภาพมา
------------------------------------------------
Roles as          3 Stereo
audio track-1     Stereo   All Dialogue  All Effects  All Music
audio track-2     Stereo   All Dialogue  All Effects  All Music
audio track-3     Stereo   All Dialogue  All Effects  All Music
video track                All Titles    All Video

ค่าเริ่มต้นที่ผิดคือ Multitrack MXF File
ซึ่งจะได้เสียงเป็น Mono ทีละช่อง ไม่ใช่ 3 คู่
