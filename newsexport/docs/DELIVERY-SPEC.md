# ข้อกำหนดการส่งไฟล์ (ยืนยันจากหน้าจอจริงแล้ว)

เอกสารนี้บันทึกค่าจริงที่ยืนยันจากหน้าจอของผู้ใช้ เมื่อ 28 ก.ค. 2569
ทุกค่าในนี้ **ไม่ใช่การเดา** — อ่านมาจากหน้าต่างตั้งค่าของ Final Cut Pro โดยตรง

---

## 1. ค่าตั้งของงาน (Project Settings)

| รายการ | ค่า |
| --- | --- |
| Starting Timecode | `00:00:00:00` |
| Video Format | 1080i HD |
| Resolution | 1920 × 1080 |
| Rate | **25i** (25 เฟรมต่อวินาที แบบอินเทอร์เลซ) |
| Rendering Codec | Apple ProRes 422 |
| Color Space | Standard — Rec. 709 |
| Audio Channels | Stereo |
| Audio Sample Rate | 48 kHz |

**ผลต่อการเขียนโปรแกรม:** ตัวส่วนของเวลาต้องเป็น 25
ตำแหน่งตัดทุกจุดต้องลงเฟรมพอดี ไม่มีเศษ

---

## 2. ไฟล์ส่งแบบที่ 1 — MOV

ใช้ปลายทางชื่อ **Export File** (ของที่มากับ Final Cut Pro)

| รายการ | ค่า |
| --- | --- |
| Format | Video and Audio |
| Video Codec | Source — Apple ProRes 422 |
| Resolution | 1920 × 1080 |
| Color Space | Standard — Rec. 709 |
| Audio Format | Linear PCM |
| Audio Layout | Stereo (L R) · 48 kHz |
| Include chapter markers | ติ๊กถูก |
| Action | Save only |
| นามสกุล | `.mov` |

ขนาดโดยประมาณ 2.93 GB ต่อความยาว 3 นาที 1 วินาที

---

## 3. ไฟล์ส่งแบบที่ 2 — MXF-50

ใช้ปลายทางชื่อ **MXF-50** (ผู้ใช้ตั้งไว้เองในเครื่องแล้ว)

| รายการ | ค่า |
| --- | --- |
| Format | MXF |
| Video Codec | **AVC-Intra (Class 50)** |
| Resolution | **1440 × 1080** |
| Color Space | Standard — Rec. 709 |
| Audio Format | Linear PCM |
| Action | Save only |
| นามสกุล | `.mxf` |

ขนาดโดยประมาณ 1.39 GB ต่อความยาว 3 นาที 1 วินาที

> หมายเหตุ: ความละเอียด 1440 × 1080 เป็นเรื่องปกติของ AVC-Intra Class 50
> ภาพจะถูกบีบด้านกว้างแล้วยืดกลับตอนเล่น ผลลัพธ์บนจอยังเป็น 16:9 เหมือนเดิม

### การตั้งค่า Roles ของ MXF-50

`Roles as:` = **3 Stereo**

| แทร็ก | Channels | Roles ที่ใส่ไว้ |
| --- | --- | --- |
| video track | — | All Titles · All Video |
| audio track-1 | Stereo | All Dialogue · All Effects · All Music |
| audio track-2 | Stereo | All Dialogue · All Effects · All Music |
| audio track-3 | Stereo | All Dialogue · All Effects · All Music |

รวมเป็นเสียง 6 ช่อง = คู่สเตอริโอ 3 คู่ โดยทั้ง 3 คู่มีเนื้อเสียงเหมือนกัน

**ผลต่อการเขียนโปรแกรม — ข้อสำคัญที่สุด**

การแยกงานห้ามรวมเสียงหรือแปลงไฟล์เด็ดขาด
เพราะถ้ารวมเสียงเมื่อไร Roles จะหายทันที แล้วค่า 3 Stereo จะใช้ไม่ได้

ตัวแยกงานจึงใช้วิธี **คัดลอกทั้งก้อนแล้วย้ายตำแหน่ง** เท่านั้น
ไม่แตะเสียง ไม่แตะภาพ ไม่แปลงอะไรทั้งสิ้น

## 4. กติกาการตั้งชื่อไฟล์

ชื่อฐาน = ชื่อ Project ใน Final Cut Pro

ต่อท้ายด้วย `-` แล้วตามด้วยลำดับก้อน เริ่มจาก `1`
เรียงจากก้อนซ้ายสุดไปขวาสุดบนไทม์ไลน์ ห้ามสลับ ห้ามข้าม

ตัวอย่างผลลัพธ์จริงที่ต้องได้ (ยืนยันจากหน้าจอผู้ใช้แล้ว)

```
OA690728_4 (ลบ) หนุ่มขับรถตู้ชนท้ายรถ 3 คันเสียหาย(ชลบุรี)-1.mov
OA690728_4 (ลบ) หนุ่มขับรถตู้ชนท้ายรถ 3 คันเสียหาย(ชลบุรี)-1.mxf
OA690728_4 (ลบ) หนุ่มขับรถตู้ชนท้ายรถ 3 คันเสียหาย(ชลบุรี)-2.mov
OA690728_4 (ลบ) หนุ่มขับรถตู้ชนท้ายรถ 3 คันเสียหาย(ชลบุรี)-2.mxf
…
OA690728_4 (ลบ) หนุ่มขับรถตู้ชนท้ายรถ 3 คันเสียหาย(ชลบุรี)-5.mov
OA690728_4 (ลบ) หนุ่มขับรถตู้ชนท้ายรถ 3 คันเสียหาย(ชลบุรี)-5.mxf
```

**วิธีที่โปรแกรมทำให้ชื่อถูกต้องโดยไม่ต้องพิมพ์**

Final Cut Pro ตั้งชื่อไฟล์ตามชื่องานอยู่แล้ว
โปรแกรมจึงตั้งชื่องานย่อยเป็น `ชื่อเดิม-1`, `ชื่อเดิม-2`, … ไว้ล่วงหน้า
ชื่อไฟล์ที่ออกมาจึงถูกต้องเองอัตโนมัติ ไม่ต้องพิมพ์ ไม่มีโอกาสพิมพ์ผิด
